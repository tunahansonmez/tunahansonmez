## 🚀 Featured Project

### 💳 Credit Card Default Analysis

An end-to-end machine learning and analytics project built using the  
**UCI Default of Credit Card Clients** dataset containing approximately **30,000 customer records**.

The project focuses on identifying customers with a higher probability of credit default while considering the business cost of misclassification.

### 🔍 What We Worked On

- Exploratory Data Analysis
- Data cleaning and preprocessing
- Analysis of demographic and repayment behavior
- Class imbalance analysis
- Feature engineering
- Payment-to-bill and payment-delay features
- Logistic Regression
- Random Forest
- LightGBM
- Stratified Cross Validation
- Recall and PR-AUC based model evaluation
- Credit risk segmentation
- Business-focused interpretation of model results
- Power BI visualization

### 🎯 Project Focus

Since failing to identify a risky customer can be more costly than incorrectly flagging a safe customer, the project places particular emphasis on:

**Recall · Precision · PR-AUC · False Negative Cost**

🔗 **[View Credit Analysis Project](https://github.com/tunahansonmez/Credit_Analysis_Project)**
